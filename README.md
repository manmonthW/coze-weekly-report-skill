# coze-weekly-report-skill

项目周报助手 — 扣子（Coze）技能

## 功能

输入本周工作流水账（大白话即可），自动按 5 步流程生成结构化项目周报：

1. **工作分类** — 按项目管理/现场管理/技术工作/人员管理/行政事务分类
2. **状态标注** — 自动识别已完成/进行中/待启动
3. **套用模板** — 生成标准四章节周报
4. **风险识别** — 智能识别进度/质量/成本/人员/流程风险
5. **下周建议** — 基于本周进展推导下周行动

## 使用方式

1. 在扣子编程（code.coze.cn）首页，点击"导入项目" → "GitHub 导入"
2. 选择本仓库
3. 导入后在技能列表中可见"项目周报助手"
4. 部署技能后，在扣子对话中输入工作流水账即可触发

## 示例输入

```
周一开了项目协调会，甲方要求工期提前两周。周二去现场检查发现3号楼钢筋间距不合规，已要求整改。周三改了预算表，增加了外墙保温的费用。周四给新来的两个实习生做了安全培训。周五写了两份设计变更单，还没送审。
```
