# 工作分类参考标准

本文档为技能提供工作分类的参考依据。

## 分类体系

### 项目管理
关键词：会议、协调会、沟通、汇报、对接、甲方、监理、协调
包含：项目协调会、进度汇报、甲方沟通、监理对接、内部协调

### 现场管理
关键词：现场、巡检、检查、验收、整改、施工、质量
包含：现场巡检、质量检查、隐蔽验收、安全检查、整改跟踪

### 技术工作
关键词：图纸、预算、方案、变更、计算、设计、造价、清单、编制
包含：图纸会审、预算编制、方案编写、设计变更、造价计算、清单编制

### 人员管理
关键词：培训、考核、新人、实习生、调配、排班、带教
包含：安全培训、技能培训、新人带教、绩效考核、人员调配

### 行政事务
关键词：文件、报表、流程、审批、归档、台账、资料
包含：文件归档、台账更新、流程审批、资料整理、报表填报

## 状态判断规则

| 关键词 | 状态 |
|--------|------|
| 完成、已、搞定、做了、开了、去了、改了、写了、换了 | ✅ 已完成 |
| 在做、进行中、开始、正在、持续 | 🔄 进行中 |
| 还没、待、计划、准备、下周、拟、将 | ⏳ 待启动 |

## 风险识别关键词

| 关键词 | 风险类型 |
|--------|----------|
| 提前、延期、工期、赶工 | 进度风险 |
| 不合规、问题、缺陷、返工、整改 | 质量风险 |
| 增加费用、超预算、变更 | 成本风险 |
| 新人、实习生、未培训 | 人员风险 |
| 未审批、还没送审、待确认 | 流程风险 |
| 安全隐患、事故、违章 | 安全风险 |
